# Momentum JSON data

This directory is generated by:

```bash
node scripts/generate-momentum-data.js
```

Do not edit generated JSON manually. Add or update `*_BI.csv` files in `data/`, then run the generator or let GitHub Actions update this folder automatically.

Generated files:

- `manifest.json`: generation metadata and logic summary
- `index.json`: one row per match
- `matches/{matchId}.json`: match timeline, possession values, peaks
- `players/{matchId}.json`: player momentum contribution for the match
- `review_clips.json`: high-impact review candidates
